# Supermarket Mobile App

Este é um aplicativo móvel simples para um supermercado, desenvolvido usando React Native e Expo.

## Funcionalidades

- **Home**: Visualize todos os produtos disponíveis.
- **Login**: Faça login no aplicativo.
- **Carrinho**: Adicione produtos ao carrinho, visualize e remova itens.
- **Criar Usuário**: Crie uma conta no aplicativo.

## Requisitos do Sistema

- Node.js
- Uso do Expo app
